# Controls UX Specification

## Principle
Controls remain FIFA Online 4-style. U1 improves discoverability only; it does not remap actions.

## Three information layers
1. Contextual hints during play
2. Compact quick reference in pause
3. Full controls reference

## Contextual hints
- Attack and defense hints change with actual control mode.
- Show only the most relevant actions.
- Advanced combinations appear in the full reference, not permanently on the HUD.
- Hints must match the action map in code.

## Full reference
Group by:
- Movement
- Attack
- Defense
- Advanced actions
- Camera and system controls

Each row contains key, action, and short usage description.

## Accessibility
- All controls views are keyboard navigable.
- Keycaps have readable contrast and text labels.
- Do not rely on color alone.

## Acceptance
- No documented key conflicts with the implementation.
- A new player can find pass, through pass, shoot, sprint, tackle, switch, and pause without leaving the game.
